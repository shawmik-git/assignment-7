# 🛒 বাজার দর (BazarDor)

প্রয়োজনীয় পণ্যের দাম এক নজরে — daily Bangladeshi market prices with price-change tracking.

## Technologies
Next.js 14 (App Router) · Tailwind CSS · DaisyUI · BetterAuth (email/password, Google, GitHub) · MongoDB · react-hot-toast

## Features
1. Live price ticker (marquee) with ▲/▼ change percentages
2. Top 6 risers and fallers on the home page plus full product grid
3. Category pages with Bengali-aware price sorting and skeleton loaders
4. Protected product detail pages with min / max / average and per-bazar prices
5. BetterAuth sign in / sign up with social login, toasts, profile and name update
6. Fully responsive, custom 404 page

## Setup
`cp .env.example .env` → fill values → `npm i && npm run dev`
